# Pro Math Context Pack

For mathematical acceleration questions, send Pro one coherent pack instead of
isolated logs.

Include:

- baseline paper/model reference or a distilled formulation;
- current master, subproblem/separation, and cut formulas;
- accepted default or benchmark config;
- bottleneck summary with runtime decomposition and traces;
- failed engineering acceleration matrix;
- implemented prototype summaries;
- exact mathematical question and desired output format.

Ask Pro for:

- TeX-level theorem statements and proof sketches;
- algorithm box;
- local oracle tests;
- certificate boundary wording;
- explicit adopt/reject criteria.

Prefer a downloadable `.tex` response. If unavailable, request one fenced
`tex` block and save it as an artifact before implementation.
