## Design decisions
- Used a local reference-track representation for fixed first-stage decisions:
  - `FixedFirstStagePlan`
  - validated binary `z[n]`, nonnegative charger counts, valid bus ids, and no chargers where `z[n] = 0`
- Used a local validated outage representation:
  - `FixedOutageVector`
  - normalized to canonical line ordering and restricted to binary `{0,1}`
- Built the reference LP directly on top of `CanonicalInstance` from Round 01.5 without reading raw data files.
- Kept the disaster model active-power-only and linear:
  - no reactive power variables
  - no voltage variables
  - no disaster substation purchase variable
- Required explicit disaster-objective-ready `critical_buses` before model build via the existing instance-layer gate.
- Used `gurobipy` for the auditable LP build and solve path because it is already available in the environment and supports direct LP dumps.
- Added minimal audit helpers only for this round:
  - LP dump writer
  - compact residual summary for Eq. (27), variable/constraint bounds, and failed-line flow checks

## Equation coverage
- Eq. (26): objective minimized as `sum_{ts,n} CLS_n * yls[ts,n]`
